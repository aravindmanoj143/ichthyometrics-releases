# IchthyoMetrics

Measure fish from calibrated photographs: scale from a ruler, landmarks in a fixed
order with a picture guide, truss and traditional measurements, ratio tables, size
correction, and exports for MorphoJ, PAST, R (geomorph) and Excel.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| System | File | Install |
|---|---|---|
| Windows 10 / 11 | `IchthyoMetrics_<version>_x64-setup.exe` | Run it. If SmartScreen warns, choose *More info -> Run anyway*. |
| macOS 11+ (Apple Silicon and Intel) | `IchthyoMetrics_<version>_universal.dmg` | Open it, accept the licence, drag IchthyoMetrics to Applications. First start: right-click the app -> *Open*. |

The app works offline; your photos and data stay on your computer.
